# Connect Four

A simple, clean Connect Four game implemented in C# (.NET 10.0) that runs directly in the console.

## Features
- **Two Game Modes**:
  - Human vs. Human
  - Human vs. AI (random column moves)
- **Modern C# Implementation**: Uses top-level statements, primary constructors, switch expressions, and LINQ.

## Requirement
- [.NET SDK 10.0](https://dotnet.microsoft.com/download) or higher.

## How to Run

1. Open your terminal in the repository root directory.
2. Run the application:
   ```bash
   dotnet run --project ConnectFour
   ```
3. Follow the console prompt to select a game mode and start playing!
